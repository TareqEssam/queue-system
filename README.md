# QueueSystem — Production Candidate

نظام إدارة طوابير قائم على ASP.NET Core / .NET 8 / SQLite / SignalR، مع صفحات منفصلة للعميل والباحث والمدير.

## ما تم إصلاحه في هذه النسخة

- تحديث لحظي لشاشات الباحث والمدير والعملاء عبر SignalR، مع Polling احتياطي للعميل.
- بث تسجيل العميل الجديد فورياً للموظفين والمديرين.
- إشعار العميل عند اقتراب دوره عند بقاء رقمين ثم رقم واحد.
- إشعار الاستدعاء، التخطي، التحويل للمدير، وإنهاء الخدمة.
- انتقال العميل مباشرةً إلى شاشة المتابعة بعد الموافقة على الإرسال، بدون خطوة اختيارية إضافية.
- الاحتفاظ بالتذكرة محلياً ليستعيد العميل المتابعة بعد إغلاق المتصفح.
- إنهاء الاتصال اللحظي عند الحالات النهائية، مع الإبقاء على رسالة نهاية الخدمة وتعليمات متابعة الطلب.
- دعم العربية والإنجليزية في شاشة التسجيل والمتابعة ورسائل النهاية والتنبيهات وتعليمات الهاتف وواتساب.
- معالجة التسجيلات ذات رقم العميل المكرر كسجلات مستقلة، مع استدعاء جميع التسجيلات النشطة عند استدعاء الرقم نفسه.
- شاشة الباحث تعرض جميع التسجيلات للرقم المكرر وتنفذ التحويل باستخدام RegistrationId.
- سجل إغلاق/فتح استقبال العملاء مع الوقت واسم المستخدم.
- تحسين رابط المتابعة عند الاستضافة خلف Reverse Proxy/HTTPS.
- Web Push قياسي باستخدام VAPID للمتصفحات التي تدعم Push API، بما فيها Web Apps على Safari في iOS الحديث، مع FCM/FID كمسار احتياطي للمتصفحات المتوافقة مع Firebase Web Messaging.
- طابور خلفي موحد للإشعارات حتى لا يحجز إرسال الدفع عملية الاستدعاء.
- إعدادات SQLite لتحسين السلوك تحت الحمل + فهارس للبحث على الأرقام والحالات.
- حماية معدل القراءة العامة من الانفجار تحت حمل العملاء، مع حدود منفصلة للكتابة.

## مهم قبل الإنتاج

هذه حزمة مصدر مرشحة للإنتاج بعد الفحص الساكن، وليست اختباراً حياً ناجحاً على خادم MonsterASP من داخل هذه البيئة.

قبل تشغيل العملاء الحقيقيين، يجب وضع VAPID الحقيقي، وبيانات موقع الإدارة الحقيقية، والعنوان HTTPS الفعلي على MonsterASP. FCM الاحتياطي اختياري إذا رغبت في تفعيله.

التفاصيل الكاملة موجودة في:

`docs/PRODUCTION_CHECKLIST_AR.md`

## قاعدة البيانات

لا تحذف `queue.db`. عند بدء التشغيل توجد ترقية تلقائية للأعمدة الجديدة المطلوبة بدون حذف السجلات القديمة.

## Web Push / FCM

للتنبيهات الأساسية يجب توفير:

- المفتاح العام VAPID في `wwwroot/push-config.js`.
- `WebPush:Enabled=true` وبيانات VAPID الخاصة على السيرفر فقط.

FCM متاح كمسار احتياطي، مع بيانات Web App العامة في `wwwroot/firebase-config.js` وService Account آمن على السيرفر. ملفات الأمثلة لا تحتوي أسراراً حقيقية.

## ملاحظة التحقق

تم إجراء فحص ساكن شامل للملفات بعد التعديل. بيئة التنفيذ الحالية لا تحتوي على `dotnet`/MSBuild، لذلك لا يجوز اعتبار عدم وجود أخطاء compile هنا بديلاً عن `dotnet restore` و`dotnet build` على بيئة النشر.
