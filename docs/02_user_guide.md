# دليل التشغيل — بدون نفق (استخدام محلي داخل الشبكة)

**نظام الطوابير المحلي (Portable)**  
الإصدار: 1.0  
الغرض: تشغيل النظام على جهاز المكتب للباحثين والمدير **داخل نفس الشبكة المحلية**، أو للتجربة على نفس الجهاز، **بدون Cloudflare** وبدون رابط عام على الإنترنت.

> إذا كان العملاء سيستخدمون إنترنت هواتفهم من خارج المبنى، استخدم الدليل الآخر:  
> **`01_دليل_التشغيل_مع_النفق.md`**

---

## 0) متى تستخدم هذا الدليل؟

| السيناريو | مناسب؟ |
|-----------|--------|
| تجربة على نفس الكمبيوتر | نعم |
| الباحثون على أجهزة داخل نفس الـ Wi‑Fi / LAN | نعم* |
| عملاء من إنترنت الجوال خارج الشبكة | **لا** — استخدم دليل النفق |
| لا تريد تثبيت cloudflared | نعم |

\* قد تحتاج فتح المنفذ 5000 على جدار حماية Windows للشبكة الخاصة فقط (اختياري ومتقدم).

---

## 1) المتطلبات

- Windows 10+ (64-bit) موصى به  
- أو أي نظام يشغّل .NET 8  
- **لا تحتاج** صلاحيات Administrator لتشغيل الملف التنفيذي بعد البناء  
- لبناء المشروع: .NET 8 SDK من  
  https://dotnet.microsoft.com/download/dotnet/8.0

---

## 2) فك الضغط

1. فك `QueueSystem_portable_source.zip` إلى:
   ```text
   C:\QueueSystem\
   ```
2. تأكد من وجود:
   ```text
   QueueSystem.csproj
   Program.cs
   appsettings.json
   wwwroot\
   publish.ps1
   ```

---

## 3) تعطيل النفق صراحةً

افتح `appsettings.json` (في المصدر أو داخل `publish-win` بعد البناء):

```json
"Tunnel": {
  "Enabled": false,
  "Mode": "quick",
  "CloudflaredPath": "cloudflared.exe"
}
```

احفظ الملف.  
لن يحاول البرنامج تشغيل `cloudflared`.

---

## 4) بناء وتشغيل النسخة المحمولة

### 4.1 البناء

```powershell
cd C:\QueueSystem
powershell -ExecutionPolicy Bypass -File .\publish.ps1
```

المجلد الناتج:

```text
C:\QueueSystem\publish-win\
  QueueSystem.exe
  appsettings.json
  wwwroot\
```

### 4.2 الأمان قبل التشغيل

في `publish-win\appsettings.json` غيّر:

```json
"Security": {
  "JwtSecret": "نص_عشوائي_طويل_جداً_64_حرفاً_على_الأقل"
}
```

### 4.3 التشغيل

1. انقر مرتين على `QueueSystem.exe`.  
2. افتح المتصفح على **نفس الجهاز**:
   ```text
   http://127.0.0.1:5000/
   ```
3. تحقق من الصحة:
   ```text
   http://127.0.0.1:5000/api/health
   ```
   يجب أن ترى شيئاً مثل: `"status":"ok"`

## 5) روابط الاستخدام المحلي (بدون نفق)

| الاستخدام | الرابط |
|-----------|--------|
| الرئيسية | `http://127.0.0.1:5000/` |
| تسجيل عميل | `http://127.0.0.1:5000/form/` |
| الباحث | `http://127.0.0.1:5000/employee/` |
| المدير | `http://127.0.0.1:5000/manager/` |
| متابعة | يصدر بعد التسجيل (ويعمل على نفس الجهاز/الشبكة إن أمكن الوصول) |

### حساب المدير الافتراضي
- Username: `admin`  
- Password: `[لا توجد كلمة مرور افتراضية — استخدم QUEUE_ADMIN_PASSWORD]`  
**غيّره فوراً بعد أول دخول.**

---

## 6) الوصول من أجهزة أخرى داخل الشبكة المحلية (اختياري)

### 6.1 معرفة عنوان IP للجهاز المضيف

في PowerShell:

```powershell
ipconfig
```

ابحث عن IPv4 مثل: `192.168.1.25`

### 6.2 فتح الرابط من جهاز آخر على نفس الشبكة

```text
http://192.168.1.25:5000/employee/
```

### 6.3 إن لم يفتح من جهاز آخر

1. تأكد أن الجهازين على نفس الـ Wi‑Fi.  
2. جدار حماية Windows:
   - السماح لتطبيق `QueueSystem` أو المنفذ **5000** على الشبكة **الخاصة** فقط.  
3. لا تستخدم شبكة عامة غير موثوقة بدون حماية.

> هذا ليس بديلاً آمناً عن النفق للعملاء العموميين. للعملاء على إنترنت الجوال استخدم دليل النفق.

## 7) الإشعارات في الوضع المحلي

### 7.1 بدون Firebase
- اضغط **تفعيل التنبيهات** في صفحة المتابعة.  
- ستعمل الإشعارات **والصفحة مفتوحة** (صوت + اهتزاز + إشعار المتصفح).  
- SignalR يحدّث الحالة لحظياً.

### 7.2 مع Firebase (إشعار والصفحة مغلقة)
نفس خطوات دليل النفق — القسم 7 — باختصار:

1. مشروع Firebase → تطبيق Web → VAPID → Service Account JSON  
2. `firebase-config.js` → `enabled: true` + القيم  
3. `appsettings.json` → `"Firebase": { "Enabled": true, ... }`  
4. ضع `firebase-service-account.json` بجانب `QueueSystem.exe`  
5. أعد التشغيل → من صفحة المتابعة فعّل التنبيهات  

على iPhone: أضف الصفحة للشاشة الرئيسية.

## 8) قائمة تحقق سريعة

- [ ] `Tunnel:Enabled = false`  
- [ ] تم البناء وظهرت `publish-win`  
- [ ] تم تغيير `JwtSecret`  
- [ ] `http://127.0.0.1:5000/api/health` يعمل  
- [ ] دخول المدير وتغيير كلمة المرور  
- [ ] تسجيل تجريبي + استدعاء من الباحث  
- [ ] (اختياري) Firebase للإشعارات في الخلفية  

---

## 9) أعطال شائعة

| المشكلة | الحل |
|---------|------|
| الصفحة لا تفتح | تأكد أن `QueueSystem.exe` ما زال يعمل |
| المنفذ مستخدم | أغلق برنامجاً آخر على 5000 أو غيّر منفذ Kestrel إن لزم |
| لا يصل من جهاز آخر | جدار الحماية / ليس على نفس الشبكة |
| تريد رابطاً للعملاء من خارج المبنى | استخدم **`01_دليل_التشغيل_مع_النفق.md`** |
